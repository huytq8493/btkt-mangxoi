Token WSHR

Chỉ dùng để đọc ngày tạo task và bước hiện tại

Dashboard gọi thẳng wshr.hasaki.vn để lấy dữ liệu task. API bắt buộc Bearer token, cookie đăng nhập không dùng được. Dán token vào đây — token chỉ lưu trên máy này (localStorage), không ghi vào file nên gửi file đi vẫn an toàn. Dữ liệu task lấy xong được giữ nguyên cho tới khi bấm “Làm mới” — mở lại dashboard không gọi lại API. Muốn dữ liệu đi theo file (gửi cho người không có token, hoặc xoá cache trình duyệt vẫn còn) thì bấm 💾 Lưu vào file rồi chép đè lên file cũ. Muốn người nhận thấy luôn thì mở file bằng Notepad, tìm dòng const WSHR_TOKEN = ""; và dán token vào giữa hai dấu nháy.
